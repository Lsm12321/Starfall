# 星陨：最后的微光 / STARFALL

Unity 6 制作的二次元科幻风 2D 俯视角生存肉鸽。移动躲避逐层升级的敌潮、自动攻击、拾取星尘升级、组合武器，并在三个相隔较远的阶段击败守关 Boss。

## 下载游玩

前往 [Releases](https://github.com/Lsm12321/Starfall/releases) 下载最新的版本。
现版本支持Windows端和Android端。

- 仓库只包含 Unity 工程源码，不含构建产物。需要从源码运行或自行打包，见下方「打开与构建工程」。

## 操作方式

- 主菜单点击“选择驾驶员”，在角色档案中查看立绘、人设、武器和被动，再点击“开始远征”。
- WASD / 方向键移动；空格向当前移动方向冲刺，短暂无敌，冷却 3.2 秒。
- 武器自动瞄准和攻击。升级时点击卡牌，或按 1 / 2 / 3；R 刷新选项，普通强化每局 3 次、武器选择每局 1 次。
- C 查看当前角色状态（立绘、属性、武器与加成），再次按 C 或 Esc 关闭；Esc 暂停 / 继续。主菜单和暂停页可静音或退出。
- Android 横屏：左侧触摸生成浮动摇杆，右下角点击冲刺；左上角“角色”打开状态页，右上角按钮暂停。移动与冲刺支持多指操作。
- 桌面视口保持 16:9；触屏视口保持 20:9，并在系统安全区内居中，避开刘海与手势区域。其他屏幕比例通过留黑边完整显示界面。

## 玩法内容

- 五种可组合武器，每种最高五级：星芒脉冲（1级伤害 18）、余烬散射（每发 16、3 枚弹体）、环轨光刃（3 枚、每次命中 20）、连锁电弧（首个目标额外承受 30% 伤害）、冰晶长枪（1级伤害 30）。冰晶长枪采用狙击弹风格：长弹体、18 起步弹速、约 1.40 秒起步射击间隔、基础穿透 4，并施加霜缓。
- 武器选择页只提供尚未拥有的新武器或已有武器的一次性进化，不能在此页提升武器等级；满级与否都可以进化。进化会继承当前等级和伤害，在此基础上改变攻击方式并使综合输出约提升 30%–125%：星链三向齐射、双生交叉散射、六曜环阵、超导电弧网络、极光三向裂变。
- 20 个独立强化图标：五种武器、属性、武装补强、三种 Boss 核心与应急修复；升级卡片与角色状态页使用图标，战斗 HUD 保留核心信息。
- 普通升级可强化当前已有武器技能或选择属性，不会解锁新武器；普通强化最高 7 级，数值会随强化等级逐步提高。每累计 4 级另开武器选择页，只能从尚未拥有的武器或尚未进化的已有武器中三选一。所有武器完成一次进化后，改为伤害 +10%、攻速 +8%、暴击率 +6% 三种武装补强。
- 十类普通属性强化（首级数值，后续逐级提高）：伤害 +25%、攻击速度 +15%、移速 +10%、暴击伤害 +20%、经验拾取范围 +1.5 / 2 / 2.5 米、暴击率 +10%、穿透 +1、每秒回复 +1.0、护甲 +8%（强化上限 5 级），以及生命上限 +20 并立即恢复 40 点生命。伤害、攻速、移速在加算区累加，再乘角色天赋、Boss 核心与武装补强；强化有等级上限，选项尽量平衡分布。
- 当前四种基础敌人构成一级敌潮；击败 Boss 1 后保留这些敌人并加入相位枪骑、回响幽灵、裂隙重装三种二级敌人；击败 Boss 2 后继续保留前两级敌种，再加入新星掠袭者、攻城星核、虚无巨噬三种三级敌人。新敌种分别带有突刺、远程弹幕、重甲或环形攻击。敌潮每 36 秒加压。
- 星尘经验、医疗掉落、补给宝箱、冲刺与受伤无敌时间、暴击数字、电弧和警示圈。
- 03:00 迎战 Boss 1「噬影守望者」。选择核心后进入至少 02:00 的二级敌潮，再迎战 Boss 2「回响先驱」；其会绕场移动、预告后跃迁并交替释放扇形弹幕和旋转弹幕。再次选择核心后进入至少 02:30 的三级敌潮，再迎战 Boss 3「星蚀巨兽」；它是不可移动的巨型场景级 Boss，以覆盖范围更大的星蚀弹幕和核心脉冲攻击玩家。每位 Boss 有两阶段攻击，击杀时触发慢动作、镜头震动、能量爆发与专属音效。
- 前两位 Boss 击杀后可选择一项核心强化并恢复满血；第三位 Boss 击杀后直接进入胜利结算，不再弹出核心选择页。超载核心提供最终伤害 +30%、最终攻速 +20%、暴击率 +20%；凤凰协议提供生命上限 +30、护甲 +10%、每秒回复 +2 和受击时 30% 免伤概率；星核共鸣提供暴击率 +30%、暴击伤害 +50%，且暴击率超过 100% 后每溢出 1% 增加 2% 暴击伤害。每种核心一局只能获得一次，已获得的核心会从后续奖励中移除。
- 五名驾驶员和三名 Boss 均以 Blender 可编辑 3D 模型制作并渲染为局内透明精灵；驾驶员服装、发型、配色和武器根据角色档案与人设立绘定制。Boss 头像随战斗阶段显示在 HUD，三个阶段使用各自的竞技场美术。
- 主菜单、角色档案、中文升级说明、血条、经验条、武器栏、冷却条、Boss 血条、暂停、胜负结算、再次远征、最佳击杀和通关次数保存；原创程序音效可静音。

## 打开与构建工程

使用 Unity Hub 打开本目录并选择 Unity `6000.0.47f1`。等待导入后打开 `Assets/Scenes/Main.unity` 并点击 Play，再选择驾驶员开始游戏。项目使用内置渲染管线和旧输入接口，无需配置预制体或 UI 引用。

Windows 打包：Unity 菜单 `Starfall > Build Windows game`。自动生成的 Main 场景不要放置需要保留的手工关卡对象。
